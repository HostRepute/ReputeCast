# ReputeCast logo

The mark is an envelope whose flap is a check: mail that was checked before it went out, and landed. Built on a 32-unit grid, 2.4-unit strokes with round caps, on an 8-unit-radius square in teal `#0F766E`.

| File | Use |
|---|---|
| `reputecast-mark.svg` | Primary mark, teal square, white strokes. App chrome, favicon source, social. |
| `reputecast-mark-ink.svg` | Mark on ink `#0B1220` for dark UI chrome. |
| `reputecast-mark-white.svg` | White square with teal strokes, for photos and teal backgrounds. |
| `reputecast-mark-mono-ink.svg` / `-mono-white.svg` | One-colour strokes, no square: print, embossing, watermarks. |
| `reputecast-logo-horizontal*.svg` | Mark + wordmark lockups (colour, white, mono). Default for headers, README, slides. |
| `reputecast-logo-stacked*.svg` | Centered lockup for avatars with text, cards, splash. |
| `reputecast-app-icon.svg` | 1024 export with a 22.5 percent corner radius for app stores and PWA. |
| `reputecast-avatar.svg` | Circular crop for GitHub, Discord, X. |
| `reputecast-favicon.svg` | Heavier 3-unit strokes so it stays legible at 16 and 32 px. |

Rules: clear space around any lockup is half the mark's height; the mark is never smaller than 16 px, the horizontal lockup never narrower than 120 px. Keep the strokes white on teal or ink, or teal on white; never recolour the check alone, never rotate, stretch, add shadows or outline the wordmark. The wordmark is IBM Plex Sans Bold with -2 percent tracking; outline the text to paths before sending files to print or to anyone without the font.
