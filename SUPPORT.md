# Getting help

- **Installing and running ReputeCast:** the [self-hosting guide](docs/deploy/README.md),
  [configuration](docs/deploy/configuration.md) and
  [reverse proxy and TLS](docs/deploy/reverse-proxy.md).
- **Questions:** ask in [Discussions](https://github.com/hostrepute/reputecast/discussions).
  Search first; someone may have asked already.
- **Bugs:** open an [issue](https://github.com/hostrepute/reputecast/issues/new/choose)
  with the version, how you run it, and the steps that show the problem.
- **Security problems:** follow [SECURITY.md](SECURITY.md) instead of opening
  an issue.
