1. API key

Open Mailgun API keys Keys are checked with a read-only call (GET /v3/domains) and stored encrypted.

2. Webhooks

Endpoint not reachable from the internet
Mailgun has to call ReputeCast to report deliveries, bounces and complaints. ReputeCast tried to reach its own public URL the way Mailgun would, and failed.
FailedSelf-test of https://reputecast.acme.io/hooks/mailgun/2b7eECONNREFUSED · DNS resolves to 10.0.4.18, a private address
SkippedRegister webhooks: delivered, permanent_fail, temporary_fail, complained, unsubscribedafter the endpoint is reachable
How to fix
Set a public URLReputeCast is running at a private address. Set PUBLIC_URL in your docker compose .env to the HTTPS address your reverse proxy exposes, then restart.
PUBLIC_URL=https://reputecast.acme.io
Or use a tunnel while testingFor a laptop or staging box, expose port 8080 with Cloudflare Tunnel or ngrok and paste the URL here.
Or poll instead of webhooksMailgun keeps an events API. ReputeCast can poll it every minute. Slower, and bounce protection during a send lags by up to a minute.
