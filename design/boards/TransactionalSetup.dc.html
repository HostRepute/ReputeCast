HTTP API

Base URL https://reputecast.acme.io/api/v1/workspaces/acme-newsletter/transactional
MethodPathWhat it does
POST/messagesSend one message. Answers 202 with the message ID.
POST/messages/batchUp to 100 messages, each with its own recipient and data.
POST/templates/{id}/renderRender subject, HTML and text without sending.
GET/messagesThe log, filtered by recipient, status, template, tag or metadata.
GET/messages/{id}One message with its timeline.
Authentication
Authorization: Bearer <key> · the key needs transactional:send
Idempotency
Idempotency-Key header · a retry within 24 hours never sends twice
Message size
Up to 10 MB with attachments on this route (Postmark's limit; SES allows 40 MB)
Rate
50 requests per second per key, set on each key
Scheduling
send_at up to 72 hours ahead
OpenAPI documentWebhooks for message events

r = requests.post(
    "https://reputecast.acme.io/api/v1/workspaces/acme-newsletter/transactional/messages",
    headers={
        "Authorization": f"Bearer {os.environ['REPUTECAST_KEY']}",
        "Idempotency-Key": f"pwreset-{user.id}-{token.id}",
    },
    json={
        "template": "password-reset",
        "to": {"email": user.email, "name": user.name},
        "data": {
            "first_name": user.first_name,
            "reset_url": reset_link,
            "expires_in": "30 minutes",
        },
    },
    timeout=10,
)
