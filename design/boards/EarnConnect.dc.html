Step 2 of 6

Create a restricted key

A restricted key can do only what ReputeCast needs. Secret keys are refused: they give full access to your Stripe account, including payouts.
Recommended: start with a test keyCheckout then runs with Stripe's test cards and nothing is charged, so you can try every page first. Add the live key when you're ready; each key gets its own webhook.

The 13 permissions the key needs

In Stripe: Developers › API keys › Create restricted key. Leave everything else at None.
