How seeds connect

Use mailboxes that exist only for tests. ReputeCast only looks for messages that carry a test token, but it can read the whole mailbox.
Gmail, Google Workspace, Outlook.com, Microsoft 365OAuth or an IMAP app password. OAuth uses this instance's own Google and Microsoft sign-in apps (Instance admin › Authentication) and asks for read-and-modify mail access only when a seed is connected.
Yahoo, iCloud, AOL, GMX, Web.deAn IMAP app password. The IMAP host and port are filled in for you.
gmail.com seedsGoogle limits mail access for apps it hasn't verified, so a gmail.com seed connected by OAuth may have to sign in again every 7 days. Use an app password.
Outlook's Focused and OtherRead through OAuth only. Over IMAP, a copy in either shows as Inbox.
