Give ReputeCast a key that can write

In the store's WordPress admin
  1. Open WooCommerce › Settings › Advanced › REST API.
  2. Edit the key named ReputeCast and set Permissions to Read/Write, or add a new key with Read/Write.
  3. If it's a new key, paste it in Settings › Integrations › WooCommerce › Replace the key.
ReputeCast checks the key when it's saved. Coupons are created 100 at a time with one use each, once per customer.
