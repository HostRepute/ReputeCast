2. Bounce mailbox

Required for SMTP
Mailbox providers send delivery failures (DSNs) back to the return-path address. ReputeCast polls that mailbox, parses each DSN and ARF report, and turns it into the same normalized bounce or complaint event other providers deliver by webhook.

What SMTP can and can't do here

YesBounces and complaints via the bounce mailbox, usually within a few minutes of the event
YesShared suppression list, auto-pause thresholds, per-mailbox-provider throttling
PartialDomain setup: ReputeCast tells you the DNS records; it can't add them to the server for you
PartialDelivered events: inferred from the SMTP 250 reply, not from the mailbox provider
NoQuota and rate discovery, batch sending, sandbox mode
