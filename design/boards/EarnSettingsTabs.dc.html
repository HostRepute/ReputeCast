Access

Access rules

What paid access does when payments fail, subscriptions end or refunds are made
When a payment fails
Always
A canceled subscription keeps access until the end of the paid period.
A refund doesn't end access by itself. Cancel the subscription too, here or in Stripe.
A trial that ends without payment ends access.
Rules apply from the next Stripe event. Changing them is recorded in the audit log.

Conversion API

For your product: record upgrades and orders with a value. Answers 202 with how the conversion was matched. Errors follow RFC 9457.

Manage keys
await fetch("https://reputecast.acme.io/api/v1/workspaces/acme-newsletter/conversions", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.REPUTECAST_CONVERSIONS_KEY}`,
    "Idempotency-Key": `upgrade-${account.id}-${invoice.id}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    click_token: req.cookies.rc_click,   // from ?rc_click=…, if present
    email: user.email,
    name: "Upgraded to Team plan",
    value: "29.00",
    currency: "USD",
  }),
});
// 202 Accepted → { id: "0192f3a0-…-7d1e", matched: "click_token" }
