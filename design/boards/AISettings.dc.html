Features and what each one sends

All on when connected. Each one sends only what it says here.
Subject ideasSends: The subject, the preheader, the email's text without images, its language, and the subject rules ReputeCast checks.
Rewrite, shorten and toneSends: The selected text and the instruction, if one is typed.
Translate a language versionSends: The source version's text, block by block, its subject and preheader, and the target language.
Alt textSends: The image, resized to 1,024 px, and the text around it.
Accessibility fixesSends: Link text that says nothing, or an image without alt text, with the text around it.
Describe the segmentSends: The description typed, and the condition schema: field names and types, list, segment and tag names, tiers. No values from any contact.
Report summariesSends: The report's aggregate numbers. No addresses.
What leaves this instanceSent
  • Only what a person is working on, only when they ask, and only for the features switched on here.
  • Liquid tokens as written, such as {{_lq0}}, never filled in. A preview “as a contact” is never sent.
  • Report summaries send aggregate numbers. They aren't contact data, but they do leave the instance.
Never sent: contacts, addresses, names, field values, recipient lists, keys or credentials.Nothing from this assistant is sent to HostRepute.
