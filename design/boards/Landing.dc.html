The newsletter platform that protects your inbox placement.

ReputeCast tells you whether a campaign will reach the inbox before you send, and guards your sender reputation while it sends. It delivers through your own Amazon SES, Postmark, Mailgun, SendGrid, Resend, Postal or any SMTP server, with several providers at once and no lock-in.

docker compose -f https://get.reputecast.com/compose.yml up -d
One command. Postgres and the app. Then open localhost:8080 and connect a provider: most take 10–15 minutes.

Before you send

Send Readiness

Blocklists across 80+ sources, SPF/DKIM/DMARC/BIMI against each provider's required records, spam triggers, Gmail's clipping limit, broken and blocklisted links, one-click unsubscribe, audience quality and routing health. Every check is Pass, Warn or Block, with a fix.

While you send

Guarded sending

Live delivered, bounced and complained counts per mailbox provider and per sending provider. Bounces or complaints over your thresholds pause the campaign, or just one route, and ReputeCast explains what happened and offers resume, adjust, fail over or cancel.

Any provider, several at once

Pluggable sending providers

Built-in adapters for SES, Mailgun, SendGrid, Postmark, Resend, SparkPost, Mailjet, Brevo, Azure, Postal and SMTP. Weighted splits for warm-up and migration, automatic failover, one shared suppression list, and an adapter SDK for anything else.

Everything a newsletter tool should have. All of it free.

No paid tier, no feature flags behind a licence key. If it's in the product, it's yours.

Drag-and-drop composer

Built on GrapesJS with MJML, so emails render in Outlook. Device, client and dark-mode previews, personalization with fallbacks, A/B variants, inline deliverability warnings.

Visual automations

Flows on React Flow: triggers, delays, emails, branches, A/B splits, webhooks, list actions and goals, with live stats on every step and versioned publishing.

Honest analytics

Human opens separated from Apple Mail prefetches, a click map, bounces mapped to one taxonomy with the provider's original code, results per mailbox and per sending provider.

List health

Active, Cooling, At risk and Sunset tiers, a sunset policy, and one suppression list shared by every provider.

10-minute provider setup

SES via CloudFormation with SNS and configuration sets created for you, API keys for the rest, a bounce mailbox for SMTP, DNS records with live verification, a test send.

Migration that keeps consent

Import from Brevo, Mailchimp, MailerLite, listmonk, Keila or CSV. Unsubscribed and bounced contacts stay suppressed, forever.

Segments without SQL

A condition builder with AND/OR groups and a live count. The generated SQL is one click away for people who want it.

Forms and public pages

Embedded, popup and hosted forms with double opt-in and spam protection; preference center, unsubscribe with a "fewer emails" option, public archive.

Teams, API, MCP

Roles with granular permissions, OIDC SSO, passkeys, scoped API keys, signed webhooks, an audit log, and an MCP server so AI agents can draft and report with approvals.

Install in one command

Docker Compose brings up Postgres, the app and the workers. Upgrades are one pull away. Backups are a pg_dump.

  1. Run the compose command.
  2. Open localhost:8080 and create the owner account.
  3. Connect a sending provider: most take 10–15 minutes, DNS included. Amazon SES takes longer when ReputeCast doesn't run on AWS, and a new AWS account can wait up to 24 hours for production access.
  4. Import contacts with consent intact, send a test, go.
curl -fsSL https://get.reputecast.com/compose.yml -o compose.yml
docker compose up -d
# open http://localhost:8080
Read the install guideReleases
Requirements: Docker 24+, 2 vCPU, 4 GB RAM, a domain you control. Helm chart and bare-metal guides in the docs.
