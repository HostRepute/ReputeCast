The newsletter platform that protects your inbox placement.

ReputeCast tells you whether a campaign will reach the inbox before you send, and guards your sender reputation while it sends. It delivers through your own Amazon SES, Postmark, Mailgun, SendGrid, Resend, Postal or any SMTP server, with several providers at once and no lock-in.

curl -fsSLO https://get.reputecast.com/compose.yml &&

One command. Postgres and the app. Then open localhost:8080, sign in with the temporary password from the app's logs and connect a provider: most take 10–15 minutes.

Before you send

Send Readiness

Eight major blocklists built in (84 with HostRepute), SPF/DKIM/DMARC/BIMI against each provider's required records, spam triggers, Gmail's clipping limit, broken links and link domains looked up live, Gmail and Yahoo sender rules, one-click unsubscribe, audience quality and routing health. Every check is Pass, Warn or Block, with a fix.

While you send

Guarded sending

Live delivered, bounced and complained counts per mailbox provider and per sending provider. Bounces, deferrals or complaints over your thresholds slow or pause the campaign, or just one route, and ReputeCast explains what happened and offers resume, adjust, fail over or cancel. New domains and IPs start with a canary.

Any provider, several at once

Pluggable sending providers

Built-in adapters for SES, Mailgun, SendGrid, Postmark, Resend, SparkPost, Mailjet, Brevo, Azure, Postal and SMTP. Weighted splits, warm-up caps enforced as mail goes out, failover only to a provider that passes its checks, one shared suppression list, and an adapter SDK for anything else.

Everything a newsletter tool should have. All of it free.

No paid tier, no feature flags behind a licence key. If it's in the product, it's yours.

Drag-and-drop composer

Built on GrapesJS with MJML, so emails render in Outlook. A Write mode, device, client and dark-mode previews, personalization with fallbacks, A/B variants, a brand kit, inline deliverability and accessibility warnings, and AI suggestions through your own model key.

Visual automations

Flows on React Flow: up to three triggers, delays, emails, texts, push and WhatsApp steps, branches, A/B splits, webhooks, list actions and goals, with live stats on every step, test sends and versioned publishing.

Honest analytics

Human opens apart from Apple Mail prefetches, clicks checked against security scanners, A/B winners decided by significance, a click map per variant, bounces in one taxonomy with the provider's original code, results per mailbox and per sending provider.

List health

Active, Cooling, At risk and Sunset tiers, a sunset policy with a dry run, and one suppression list shared by every provider.

Segments without SQL

A condition builder with AND/OR groups and a live count. The generated SQL is one click away for people who want it.

Forms and public pages

Embedded, popup and hosted forms with spam protection and a double opt-in that link scanners can't confirm; preference center, unsubscribe with a "fewer emails" option, public archive.

Transactional email

Templates written in the composer, a send, batch and render API with idempotency keys, an SMTP relay, a message log and delivery alerts, on a stream that fails over and goes before broadcasts.

SMS, web push and WhatsApp

SMS through Twilio, Vonage, Plivo, Telnyx or AWS, with routing by country, consent per list, keywords and quiet hours; web push with a prompt designer; WhatsApp through Meta's Cloud API.

Grow and earn

Referrals, recommendations with partner links, paid subscriptions through Stripe, offers, gift subscriptions, sponsorships and revenue attribution.

Website, pages and a shop

A publication website with posts, members, a meter and a paywall; landing, sales and webinar pages; a shop for digital products.

In your readers' languages

Language versions of campaigns, automation emails and transactional templates, forms and pages in each language, and the app itself in English, French, German, Spanish and Vietnamese.

Guided provider setup

SES via CloudFormation with SNS and configuration sets created for you, API keys for the rest, a bounce mailbox for SMTP, DNS records with live verification, a test send. Most take 10–15 minutes.

Migration that keeps consent

Import from Brevo, Mailchimp, MailerLite, listmonk, Keila, CSV or XLSX. Unsubscribed and bounced contacts stay suppressed, forever.

Privacy built in

Erasing a contact reaches every table that holds their data, a contact's export is complete, and open and click details and unconfirmed signups expire on the schedule you set.

Teams and agencies

Roles with granular permissions, send approvals, OIDC SSO, passkeys and an audit log. Agencies run client workspaces with staff assignments, client sign-off and usage per client.

API, MCP and integrations

An OpenAPI 3.1 REST API, scoped keys, signed webhooks, and an MCP server whose agents pass the same permission checks as people. Zapier, Make and n8n apps, a WordPress plugin, and Shopify and WooCommerce stores.

Install in one command

Docker Compose brings up Postgres, the app and the workers. Upgrades are one pull away. Back up with a pg_dump and the app's data volume, which holds the secret key and uploads.

  1. Download the compose file and start it with your email for the first Owner.
  2. Open localhost:8080 and sign in with the temporary password from the logs.
  3. Connect a sending provider: most take 10–15 minutes, DNS included. Amazon SES takes longer when ReputeCast doesn't run on AWS, and a new AWS account can wait up to 24 hours for production access.
  4. Import contacts with consent intact, send a test, go.
curl -fsSLO https://get.reputecast.com/compose.yml
REPUTECAST_ADMIN_EMAIL=you@example.com docker compose up -d
docker compose logs app | grep -A4 "ReputeCast is installed"
Read the install guideReleases
Requirements: Docker 24+ with Compose and a domain you control. Load-tested with a million contacts on 4 vCPUs; the docs cover the binary, TLS, Postgres, backups and scaling.
