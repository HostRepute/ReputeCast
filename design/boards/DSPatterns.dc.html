Send Readiness

The signature pattern. The same block appears in the composer, before scheduling, on the overview and in the landing hero. Blocks first, then warnings, then passes; every row has a finding in one sentence and the fix on the right.

Rules

1One verdict badge, top right: Ready, Ready with N warnings, Blocked. Never a score. 2Order is Block → Warn → Pass. Passes stay visible so the person sees what was checked. 3Every Block and Warn names the fix as a button, and the button does the fix where possible. 4The footer states cost, time and recipients so the decision is made with numbers. 5A Block disables the primary action; it does not hide it.

Rules

1Counters only go up. The bar shows each sending provider in its chart colour. 2A pause names the threshold, the number held and what is still moving. 3Four choices, always in this order: resume, adjust, fail over, cancel. Cancel is red text, not a red button. 4The dot pulses; the text does not blink.

Rules

1Migration and import screens always show how many contacts stay suppressed and why, before the import runs. 2There is no "import anyway" for unsubscribed or bounced addresses. The option does not exist in the UI. 3A contact profile shows the consent source, date and IP in plain words.
