# Design inventory

The prototype (`design/boards`, exported from the ReputeCast canvas) has 29
pages and 430 artboards: 288 desktop boards (1440 px; public pages 720 px)
plus Tablet (834 px) and Phone (390 px) boards that render the same markup at
narrower widths. This inventory maps every board to the spec section it
implements and the workstream that builds it (`docs/dev/WORKSTREAMS.md`).

## Design system

- Tokens: `design/design-system/tokens.json` → `web/src/styles/tokens.css`
  (generated by `pnpm tokens`). Colour (text, surfaces, lines, accent, status
  pairs, dark surfaces, code, chart palettes, publisher sample), type (IBM
  Plex Sans/Mono; app, mono and marketing scales), spacing (4 px grid),
  radius (6/8/10/14/pill), shadow, duration and easing.
- Brand book: `design/design-system/README.md` (principles, colour rules,
  type, layout, components, patterns, access/approvals patterns, motion,
  accessibility, voice).
- Shared components found on the boards and ported to `web/src/styles/app.css`
  and `web/src/components/ui`: card, button (default, primary, small, icon,
  danger), badge (ok, warn, bad, info, neutral, purple; dot, pulse), table,
  bar/track, stacked bar, input/select/textarea, label, checkbox/radio,
  toggle, option card, segmented control, pill tabs, panel tabs, underline
  tabs, chip, note (info, warn, bad, ok, neutral), banner, key-value list,
  code pane, DNS record box, diff, avatar, wizard stepper, vertical steps,
  skeleton, spinner, stat tile, dialog, menu/popover, tooltip, toast, kbd,
  full-page state, sidebar / icon rail / phone tab bar, top bar with tools
  (bell, user menu), workspace switcher.
- Motion: entrance rise, badge pop, bar grow, counters, auto-pause pulse,
  live pulse, flow "pulse through steps" (automations, landing), landing
  hero typing/marquee/scan; all disabled by `prefers-reduced-motion`.
